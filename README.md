#Calculator
a python 3 calculator used from the terminal, built step by step in SCCM4910

## what it will do
you can add subtract multiply and divide numbers and display the result

## how to run it
Run: python3 calculator.py
enter the first number, operator (+ - * /), then second number
the program prints result: followed by the answer
./run.sh use test 6*7 should give 42 then use ctrl c to exit
use source /opt/python-venv/sccm-4910/bin/activate to enter the sccm4910 environment
use ./check.sh to run the tests which should all pass
